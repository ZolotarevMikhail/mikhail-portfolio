КЕЙС 07 · АНАЛИТИКА

Дашборд продаж Wildberries

HTML/CSS/JSWB APIБез CDNСвет/тьма
Дашборд WB — тёмная тема. Та же версия поддерживает светлую. Скриншот откроется на полный экран по клику.
Задача
Селлер спортивных товаров на WB каждое утро за минуту хочет видеть реальную картину: выручку, прибыль после комиссий и рекламы, что заказывают, что заканчивается на складе. Сейчас цифры разбросаны по вкладкам личного кабинета WB — сводить вручную некогда.
Что сделал
6 KPI-плиток: выручка (с возвратами), заказы, прибыль, ROI рекламы, остатки, возвраты. 4 графика: динамика выручки/заказов/прибыли по периоду, расходы и отдача на рекламу, прибыль по товарам (рейтинг «кто зарабатывает — кто тянет вниз»), остатки по товарам. Фильтры: период (год/месяц/неделя/день + произвольные даты), тип товара. Одна кнопка «Обновить» — тянет свежие данные из API WB по требованию. Экспорт в CSV текущего среза. Светлая и тёмная тема. Авто-резюме по периоду. Таблица товаров с сортировкой.
Результат
Один HTML-файл, открывается двойным кликом. Работает офлайн, без CDN и внешних библиотек — графики на чистом SVG/JS. Демо-данные внутри файла: дашборд сразу показывает графики и KPI без настройки — можно оценить интерфейс. WB-токен хранится только в local браузера клиента, никогда не уходит в код. Готов к подключению реального кабинета селлера (режим «лайв-браузер»).
Инструменты
Claude (вайбкодинг), HTML/CSS/JS, API Wildberries (продажи, заказы, остатки, комиссии, реклама), SVG-графики. Архитектура применима и к Ozon — для другой структуры комиссий и остатков.

КЕЙС 10 · ЧАТ-БОТЫ

Реферальный бот-привратник для Telegram

PythonPostbackSQLiteАвтотесты
Задача
Впускать в приватную Telegram-группу только тех, кто выполнил условие в партнёрской системе — автоматически, без ручной проверки. Проект из практики: собственный прототип, который можно подключить к любой партнёрке или продаже доступов.
Что сделал
Пользователь заходит по ссылке с уникальным кодом — бот запоминает пару «код ↔ пользователь». Партнёрская система присылает postback (авто-уведомление через встроенный веб-сервер бота) — бот выдаёт одноразовую ссылку-приглашение в группу. Защита от повторной выдачи: каждая выдача фиксируется в базе, дубль не пройдёт. Ручная выдача админом командой /grant, выбор группы командой /setgroup прямо в чате — без правки конфигов. Опциональный секрет в postback — защита от подделки заявок. Токен и настройки — в отдельном файле, в коде их нет. Логика проверена 9 автотестами.
Результат
Рабочий бот-привратник: весь цикл «ссылка → оплата/действие → доступ в группу» идёт без человека. Хранение в одном файле базы — никаких внешних сервисов, развёртывается на недорогом сервере. Готов как шаблон под заказ клиента: под любую партнёрскую систему с postback.
Инструменты
Claude (вайбкодинг), Python, pyTelegramBotAPI, SQLite, встроенный HTTP-сервер.
