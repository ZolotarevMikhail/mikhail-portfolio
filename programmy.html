НАПОМИНАНИЯ · РАБОЧИЙ СТОЛ

Напоминалка для рабочего стола

Напоминания, которые не потеряются: не в телефоне и не в браузере, а прямо на рабочем столе. Задача со своим временем всплывает поверх всех окон в нужную минуту — пропустить невозможно.

  • Таблица задач: у каждой строки своё время и статус — ожидает / готово / просрочено, статусы подсвечены цветом.
  • Быстрые кнопки «Через 1/5/15/30 мин» и «Через 1 час» — напоминание одним нажатием, без набора даты.
  • Повторяющиеся напоминания — каждый день и каждый месяц, с честным переносом дат: короткие месяцы и високосный год расписание не ломают.
  • Всплывающие уведомления поверх всех окон; задачи — в локальной базе SQLite, ничего не теряется после перезапуска.

СЕЙФ · ПАРОЛИ

Менеджер паролей с шифрованием

Пароли в заметках и блокноте — мишень: утащили один файл — утащили все доступы. Личный сейф на своём компьютере, шифрует пароли и не отдаёт их никому, включая облачные сервисы.

  • Мастер-пароль хранится только как SHA-256-хеш — сам пароль нигде не сохраняется, из файла базы его не вытащить.
  • Пароли сайтов шифруются алгоритмом Fernet с локальным ключом, данные лежат в SQLite.
  • Простое меню: добавить / получить / список / удалить; встроенный генератор надёжных паролей (8–64 символа, выбор типов символов).
  • Найденный пароль копируется в буфер обмена — вставил и пошёл дальше. Файл базы без мастер-пароля бесполезен.

ДОКУМЕНТЫ · PDF

Генератор PDF-документов по шаблону

Счёт, акт, чек — каждый месяц одни и те же документы вручную из таблицы: путаются номера и суммы. Программа сама собирает готовый документ из таблицы с данными и бланка с фирменным дизайном.

  • Вход — CSV или JSON с данными; бланк — обычный HTML-файл с метками вида {{ поле }}: любой дизайн меняется без правки кода.
  • Программа сама считает суммы по позициям и общий итог, подставляет данные в бланк и собирает PDF.
  • Партия счетов за один запуск — один файл данных может содержать несколько документов; готовый PDF открывается сам.
  • Понятные сообщения об ошибках на русском, кириллица чистая; работает офлайн — данные не покидают компьютер.
