КЕЙС 06 · WB/OZON

Продающее SEO-описание карточки Wildberries

WBSEO-текст1000–1500 символов
Задача
Продающее SEO-описание 1000–1500 символов для массажного валика-роллера «СпинаОк». ЦА — офисные работники 25–45 лет с болью в спине. Нужно вписать 3 ключа: «массажёр для спины», «валик массажный», «роллер для спины».
Что сделал
Черновик через Claude → ручная редактура под бренд и ЦА: убрал «ИИ-шаблонщину», добавил блок «как пользоваться за 5 минут». Три ключа вписаны естественно, по одному разу, в разных падежах. Характеристики взяты из данных клиента (TPE, 33×14 см, 750 г) — без выдуманных фактов.
Результат
1014 символов — попадает в ТЗ 1000–1500. Все 3 ключа вписаны, текст читается как написанный человеком. Готов к вставке в карточку WB.
Инструменты
Claude + ручная редактура. Процесс применим к карточкам WB/Ozon в любой нише.
КЕЙС 08 · WB/OZON

Радар цен конкурентов — вкладка комплекса (Wildberries)

HTML/CSS/JSАдаптивДемо онлайн
Сравнение цен парами «мой товар × конкурент» — Δ% и автоматические выводы. Живое демо — по кнопке ниже.
Задача
Селлеру WB нужно видеть, где его цена ниже конкурента, а где конкурент обходит его — по парам товаров-аналогов, а не «в среднем по полке».
Что сделал
Дашборд одним HTML-файлом: сопоставление пар с цветовой маркировкой (🟢 мы дешевле / 🔴 конкурент дешевле), живые фильтры (товар, конкурент, порог %), авто-выводы по критичным расхождениям, загрузка среза JSON/CSV, средняя по конкурентам. Без библиотек и CDN, адаптив от 400 px.
Результат
Открывается двойным кликом и сразу показывает демо-данные. Демо доступно онлайн — можно показать заказчику без установки.
Инструменты
Claude (вайбкодинг), чистый JavaScript, SVG, GitHub Pages для демо. В комплексе «Автоматический Дашборд + Радар» радар живёт на вкладке большого дашборда; здесь — самостоятельное демо радара.

КЕЙС 12 · WB-АВТОМАТИЗАЦИЯ

Утренняя сводка Wildberries — Telegram-бот

PythonTelegram APIWB API
Задача
Продавец WB каждый день руками проверяет в кабинете: сколько продали, сколько заказов, какие товары заканчиваются. Нужно, чтобы готовая сводка приходила сама — каждое утро, без открытия кабинета.
Что сделал
Telegram-бот с данными кабинета WB: выручка и продажи вчера против позавчера, новые заказы, топ товаров, заканчивающиеся и пустые остатки с названиями. Автоотправка в 10:00 по Москве, подписка/отписка командами. Работает с официальным API WB: при отказе WB по лимиту бот сам ждёт и повторяет, а не падает.
Результат
Рабочий бот на реальном кабинете (продажи SPR). Первый кирпич «финансового стража» селлера: дальше — контроль цен, рентабельности и рекламных расходов. Код открыт на GitHub.
Инструменты
Claude (вайбкодинг), Python, Telegram Bot API, Statistics/Analytics/Content API Wildberries.

КЕЙС 15 · WB/OZON

Утренняя сводка WB + Ozon — Telegram-бот, две площадки в одном сообщении

PythonTelegram APIWB APIOzon Seller APIРабота 24/7
Задача
Селлер WB и Ozon каждое утро руками листает два кабинета и сравнивает цифры: что продалось, что заказали, какие товары заканчиваются. Нужна готовая сводка в Telegram — сама, в одно и то же время, по обеим площадкам сразу.
Что сделал
Telegram-бот, который каждый день в 10:00 по Москве присылает сводку по обоим кабинетам: выручка и продажи «вчера против позавчера» с разницей в рублях и процентах, новые заказы, топ-3 товара по выручке, заканчивающиеся товары (порог 5 штук) и закончившиеся — с названиями. По Ozon — выручка и заказанные штуки плюс те же блоки остатков. Управление командами: /summary (обе площадки разом), /ozon, /start, /stop. Надёжность: при отказе API по лимиту бот сам ждёт и повторяет (до 2 попыток); сбой Ozon не роняет WB-сводку; если ключи Ozon не настроены — бот штатно работает только по WB. Токены — в отдельном файле .env, в код и git не попадают. Работает круглосуточно: автозапуск при включении компьютера и авто-перезапуск при падении.
Результат
Проверен живым прогоном на реальных кабинетах. Вместо утреннего листания двух кабинетов — одно сообщение в Telegram. Бот подсвечивает заканчивающиеся и пустые остатки — это прямая защита выручки: позиция с нулевым остатком теряет выдачу в поиске маркетплейса. Код открыт на GitHub; продукт личный (автор — сам селлер WB/Ozon), можно установить и под ключ заказчику.
Инструменты
Claude (вайбкодинг), Python, pyTelegramBotAPI, официальный API Wildberries, Seller API Ozon, launchd (автозапуск на Mac).
